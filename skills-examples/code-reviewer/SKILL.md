# Code Reviewer

When asked to review code:

1. Read the whole change before commenting.
2. List bugs and risky behavior first, most serious first.
3. Then list style and readability issues.
4. For each issue, say where it is and suggest a fix.
5. End with one sentence on whether the change is ready to merge.

Do not rewrite the whole file unless the user asks.
