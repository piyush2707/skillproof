Eval Cards

Paste an Eval Card (.eval.json) to see how a skill did with and without it. Runs in your browser; nothing is uploaded.

Eval Cards record evidence; they do not run any agent. Check the badge: "example" means sample data, "manual" means a person ran the cases and recorded the results. Scores count pass as 1, partial as 0.5, fail as 0, and ignore untested cases. Format reference: schema/eval-card.md in the repo.
