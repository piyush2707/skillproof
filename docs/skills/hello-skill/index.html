hello-skill

Greets the user and explains what agent skills are. Use when the user asks what a skill is or wants a simple example of one.

Context cost (estimate)
About 34 tokens always loaded (name + description), about 98 in full. Estimates use ~4 characters per token.

How to install

  1. Download the folder hello-skill from the repository.
  2. Place it where your agent looks for skills. The location differs by agent, so check your agent's documentation.
  3. Ask something that matches the description and see whether the agent uses the skill.

# Hello Skill

When the user asks what a skill is, explain in two or three sentences that
a skill is a folder with a SKILL.md file that teaches an agent how to do one
task well. Then offer to show the structure of this skill.
