Conflict Map

Find skills whose descriptions overlap and may confuse an agent. Runs in your browser; nothing is uploaded.

How it works: it compares the words in each skill's name and description (ignoring common words) and scores the overlap from 0 to 100%. High overlap means an agent may have trouble choosing between the skills. It does not run any agent, so treat it as a warning to review, not proof of a clash.
