Agent skills are easy to write. Hard to trust. Let's prove them.

SkillProof checks whether a skill is well-formed, measures how much context it costs, flags skills that may clash, and records evidence that a skill works. No install, no account, nothing uploaded.

How it works

Three steps. Everything runs locally in your browser tab.

  1. Paste your SKILL.mdCopy one skill, or several separated by a line of =====.
  2. Get instant feedbackSee token estimates and overlap scores right on the page.
  3. Fix and repeatTighten descriptions, split overlapping skills, trim long bodies.

What the validator checks

Built into this repo's GitHub Actions. Skill rules are in validators/rules.json.

  • Frontmatter exists, with a name and description
  • Name uses lowercase letters, numbers and hyphens
  • Description is long enough to be useful and says when to use the skill
  • File links inside the skill actually exist
  • Length warnings for very long skill bodies
  • Eval cards have the required fields, valid results and unique case ids

Token counts are estimates (about 4 characters per token). Overlap scores are a word-based warning, not proof of a clash. Eval cards record evidence; SkillProof does not run any agent.
